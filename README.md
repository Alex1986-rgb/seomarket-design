# SeoMarket 2.0 — дизайн-макет

Кликабельные прототипы публичного сайта, личного кабинета и писем сервиса SeoMarket
(дизайн-система Industry). Живой просмотр: https://alex1986-rgb.github.io/seomarket-design/

Данные в макете условные. Фото — Unsplash, авторы подписаны в кадре. Промты для замены фото
собственной генерацией — `photo-prompts.md`. Исходник макета — `design/seomarket-v2/` в репозитории
`seomagic-saas-tool`.
